# ETAPA 3 — Front-end (Entrega Final)

Esta pasta contém apenas a parte visual:
- `index.html`: estrutura e formulário.
- `css/style.css`: cores, layout e responsividade.
- `js/app.js`: eventos e comunicação com a API usando Fetch.

## Como executar
1. Inicie o back-end dentro de `etapa-2-backend` com `pip install -r requirements.txt` e `python app.py`.
2. Deixe o Flask rodando.
3. Na pasta principal do repositório, abra outro terminal e execute `python -m http.server 5500`.
4. Acesse `http://127.0.0.1:5500/etapa-3-frontend/`.
