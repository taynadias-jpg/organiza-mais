# ETAPA 1 — Modelagem e Banco de Dados

Esta pasta reúne somente os arquivos da primeira entrega:
- `modelo_uml.md`: diagrama de classes/UML.
- `schema.sql`: criação da tabela do banco.
- `conexao.py`: conexão inicial com SQLite.

## Como testar
Na pasta principal do repositório, execute:

```bash
python etapa-1-banco-de-dados/conexao.py
```

O banco SQLite será criado nesta pasta quando o script for executado.
